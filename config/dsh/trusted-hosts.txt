# ============================================================
# 可信来访域名白名单（trusted-host）
#
# 只有列在这里的域名/IP 才能访问 DSH，其它一律 403。
#
# 为什么需要它：
#   Nginx 不再把 Host 改写成 127.0.0.1（那样会让插件跳第三方认证时
#   拼错回调地址而失败），因此必须由这里显式声明「合法来访域名」。
#   详见 docs/DESIGN.md 的 trusted-host 章节。
#
# ------------------------------------------------------------
# 写法
# ------------------------------------------------------------
#   一行一个，**不需要写端口**（写了端口则只放行该端口）：
#
#     dsh.corp.com          # 该域名的任意端口都放行（推荐）
#     10.0.0.8              # IP 也可以
#     dsh.example.com:9443  # 只放行 9443 端口
#
#   支持 `#` 注释；也支持一行写多个，用逗号 / 分号 / 空格分隔。
#
# ------------------------------------------------------------
# 生效方式（二选一，优先级：环境变量 > 本文件）
# ------------------------------------------------------------
#   1. 改本文件，然后重启容器：
#        docker restart dsh-web
#      （若以 bind mount 挂载了本文件，改完重启即可；
#        否则需重建镜像，或改用下面的环境变量方式）
#
#   2. 启动时用环境变量注入（覆盖本文件）：
#        docker run -d ... -e DSH_TRUSTED_HOSTS="dsh.corp.com,10.0.0.8" ...
#
# ------------------------------------------------------------
# ⚠ 重要：留空 = 只允许回环地址访问
# ------------------------------------------------------------
#   本文件若一条都没配（且没设 DSH_TRUSTED_HOSTS），则**只有**
#   127.0.0.1 / localhost / [::1] 能访问 —— 外部一律 403。
#   这个方向的失败是刻意设计的（fail-closed）：宁可进不去，
#   也不要因为漏配而让任意域名都能访问。
#   所以部署到服务器上时，**必须**把对外的域名或 IP 填进来。
# ------------------------------------------------------------

# ↓↓↓ 在这里填写你的域名 / IP（下面两行是示例，请按需修改或删除）

# dsh.corp.com
# 10.0.0.8
